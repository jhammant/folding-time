# Folding Time

A single-page, long-form interactive explainer: **Folding Time — How AI mapped the proteome in a year, and what that unlocked.**

Built from the public specification at https://claude.ai/public/artifacts/ddbf0c2d-4c90-4916-bd88-e334533cdda8.

Live site: https://jhammant.github.io/folding-time/

## Sources

- Levinthal, 1969, protein folding paradox
- RCSB PDB growth and 200,000-entry milestone
- CASP / AlphaFold CASP14 results
- Jumper et al., *Highly accurate protein structure prediction with AlphaFold*, Nature 2021
- AlphaFold Protein Structure Database
- AlphaFold 3, ESMFold, RFdiffusion, ProteinMPNN public papers/pages

This is an educational abstraction. It does not run biological models in the browser and does not claim predictions equal experiments.
